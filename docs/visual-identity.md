# DataTerra

A identidade combina infraestrutura digital e responsabilidade ambiental. O símbolo apresenta a letra D com linhas de dados e uma folha integrada. A assinatura usa Data em verde profundo e Terra em esmeralda, acompanhada de “Inteligência ambiental”.

## Cores

| Uso                                      | Cor       |
| ---------------------------------------- | --------- |
| Verde floresta: base do símbolo e ações  | `#064E3B` |
| Esmeralda: assinatura e destaques        | `#078665` |
| Verde-lima: detalhe da folha e navegação | `#BEF264` |
| Títulos no tema claro                    | `#15392F` |
| Assinatura no tema escuro                | `#86EFAC` |

As categorias ambientais conservam suas cores de identificação: energia, água, emissões, resíduos e recursos naturais.

## Aplicação

- Símbolo vetorial: `public/brand/dataterra-symbol.svg`, também utilizado como favicon.
- Componente reutilizável: `src/components/ui/brand-mark.tsx`.
- Tipografia: Inter. Assinatura em peso 700, com espaçamento mais fechado; descrição em caixa alta com espaçamento aberto.
- A assinatura completa aparece na navegação expandida. A navegação recolhida utiliza somente o símbolo.
- O símbolo do Instituto Federal conserva sua identidade institucional.
- As cores da assinatura são ajustadas para os temas claro e escuro.
